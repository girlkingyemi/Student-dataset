## Project Description
This project creates a fictional student dataset for 200 level students in two departments:
- Computer Science
- Mass Communication

The dataset contains student names, matric numbers, department, level, attendance percentage, and average examination score.

It is built with Python using the `pandas` library.

## Dataset Columns

| Column Name | Description |
| --- | --- |
| Student_Name | Full name of the student |
| Student_ID_Matric_No | Fictional matric number |
| Department | Computer Science / Mass Communication |
| Level | 200 |
| Attendance_Percentage | Attendance in % |
| Average_Examination_Score | Average exam score out of 100 |
